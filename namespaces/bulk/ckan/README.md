# CKAN-Geoconnex Bulk Integration

[CKAN](https://ckan.org) is a data management system used by organizations globally. There are multiple U.S. state water data hubs using CKAN to manage datasets including the [New Mexico Water Data Catalog](https://catalog.newmexicowaterdata.org) and the [Texas Water Data Hub](https://txwaterdatahub.org).

More details about how a CKAN instance can integrate with Geoconnex can be found at the bulk loader's source code located at [github.com/dathere/ckan_geoconnex_bulk_runner](https://github.com/dathere/ckan_geoconnex_bulk_runner).
